# ADR-039: El código de los servicios sale del índice; graphify es el único motor de código

Estado: aceptado. Este archivo registra en el repositorio una decisión que el código ya cumple y cita (`indexer.py`, `webhook.py`, `graph_targets.py`, `scripts/purge-code-collection.py`, la descripción de `search_code` en `src/knowledge/contract.py`). ADR-043 retira `scripts/purge-code-collection.py` junto con `chromadb`: el servidor no abre Chroma, y `migrate-index --prune-chroma` borra los archivos de Chroma, colección de código incluida.

## Contexto

El servidor embebía, además del vault, el código de los servicios en una segunda colección de Chroma (la del vault con sufijo `_code`), y `search_code` consultaba esa colección. Para relaciones, impacto y símbolos, graphify ya resuelve lo mismo desde un grafo de código local, sin costo de embeddings y sin que este servidor lea checkouts de otros servicios. Dos motores de código respondían la misma pregunta con resultados distintos.

## Decisión

1. **El servidor no embebe código.** `VaultIndexer` no crea ni consulta la colección de código; `reindex` y el webhook solo admiten `target=vault` (`code` y `all` son error). La colección que quede en disco de un índice anterior se borra con `scripts/purge-code-collection.py`.
2. **graphify es el único motor de entendimiento de código**, y corre local con su propia CLI (`graphify explain`/`affected`/`query`) contra `graphify-out/`; este servidor nunca abre ese directorio.
3. **`search_code` se degrada, no desaparece.** Sigue registrada para que un cliente con el catálogo en caché no falle contra una tool desconocida, pero toda llamada devuelve la misma redirección: `graphify explain <symbol>` y `graphify affected <file>` para relaciones e impacto, `graphify query <symbol>` solo con un nombre real de símbolo, `rg` para texto literal y `search`/`search_deep` para intención.
4. **`code.paths` pasa a `graph.targets`** en `config.json`: los repositorios que graphify incorpora, resueltos por el registro de repositorios (`knowledge.graph_targets`).

## Consecuencias

- `search_code` queda obsoleta en el contrato 1.1.0 (`_meta` `knowledge/deprecated: true`, `knowledge/removal: "2.0.0"`) y se retira en 2.0.0 (`docs/contract/CHANGELOG.md`).
- El vault no se indexa en graphify: es contenido, y su navegación es lo que resuelven las tools de este servidor.
