# ADR-039: Service code leaves the index; graphify is the only code engine

Status: Accepted. This file records in the repository a decision that the code already follows and cites (`indexer.py`, `webhook.py`, `graph_targets.py`, `scripts/purge-code-collection.py`, the `search_code` description in `src/knowledge/contract.py`). ADR-043 removes `scripts/purge-code-collection.py` together with `chromadb`: the server does not open Chroma, and `migrate-index --prune-chroma` deletes the Chroma files, the code collection included.

## Context

Besides the vault, the server embedded the services' code in a second Chroma collection (the vault's collection with a `_code` suffix), and `search_code` queried that collection. For relations, impact and symbols, graphify already resolves the same thing from a local code graph, at no embedding cost and without this server reading other services' checkouts. Two code engines were answering the same question with different results.

## Decision

1. **The server does not embed code.** `VaultIndexer` neither creates nor queries the code collection; `reindex` and the webhook only accept `target=vault` (`code` and `all` are an error). A collection left on disk by an earlier index is deleted with `scripts/purge-code-collection.py`.
2. **graphify is the only code-understanding engine**, and it runs locally with its own CLI (`graphify explain`/`affected`/`query`) against `graphify-out/`; this server never opens that directory.
3. **`search_code` is degraded, not removed.** It stays registered so that a client with the catalog cached does not fail against an unknown tool, but every call returns the same redirection: `graphify explain <symbol>` and `graphify affected <file>` for relations and impact, `graphify query <symbol>` only with a real symbol name, `rg` for literal text and `search`/`search_deep` for intent.
4. **`code.paths` becomes `graph.targets`** in `config.json`: the repositories that graphify ingests, resolved by the repository registry (`knowledge.graph_targets`).

## Consequences

- `search_code` is deprecated in contract 1.1.0 (`_meta` `knowledge/deprecated: true`, `knowledge/removal: "2.0.0"`) and removed in 2.0.0 ([`docs/contract/CHANGELOG.md`](../contract/CHANGELOG.md)).
- The vault is not indexed in graphify: it is content, and navigating it is what this server's tools resolve.
